# מערכת השאלת ספרים בספרייה: לקוח

הלקוח (React + Vite) של פרויקט הסיום בקורס ‎.NET Web API. הוא מדגים את השרת מקצה לקצה: התחברות, עיון בספרים, השאלה והחזרה, וטיפול ברור ב-**409**, כשעותק נתפס על ידי משתמשת אחרת.

השרת נמצא ב-repository נפרד: `library-server`.

**בענן:** https://library-client-h52y.onrender.com (השרת: https://library-server-cz2j.onrender.com/swagger)

השירותים בתוכנית החינמית "נרדמים" אחרי 15 דקות בלי שימוש. הפנייה הראשונה אחרי זה לוקחת בערך דקה.

## הרצה

**1.** מפעילים את השרת. ההוראות נמצאות ב-README של השרת.

**2.** מתקינים ומריצים:
```
npm install
npm run dev
```
**3.** פותחים בדפדפן את `http://localhost:5173`.

כתובת השרת מוגדרת במשתנה `VITE_API_URL`. בפיתוח היא נמצאת בקובץ `.env.development` (`https://localhost:56124`), ובענן מגדירים אותה כמשתנה סביבה. כדי שהדפדפן יוכל לפנות לשרת, השרת מתיר את כתובת הלקוח ב-CORS.

## מסכים

| מסך | מי רואה |
|---|---|
| התחברות והרשמה | כולם |
| רשימת ספרים: חיפוש, סינון לפי קטגוריה, מיון, עימוד מהשרת | כל מחוברת |
| דף ספר: עותקים וכפתור "השאילי" | כל מחוברת. ההשאלה לקוראות |
| ההשאלות שלי: תאריך החזרה, סימון איחור, כפתור "החזירי" | קוראת |
| כל ההשאלות: סינון באיחור, החזרה בשם קוראת | ספרנית, מנהלת |
| הוספת ספר, הוספת עותק, סימון עותק כלא זמין | ספרנית, מנהלת |

## הדגמת ההתנגשות (409)

ההתחברות נשמרת לכל לשונית בנפרד (`sessionStorage`), ולכן אפשר להתחבר בשתי לשוניות כשתי קוראות שונות:

1. **לשונית 1**: מתחברים כ-`reader1@library.local`, ונכנסים לספר "הסוד של מחנה הקיץ", שיש לו עותק יחיד.
2. **לשונית 2**: מתחברים כ-`reader2@library.local`, ונכנסים לאותו ספר.
3. בלשונית 1 לוחצים "השאילי". ההשאלה מצליחה.
4. בלשונית 2, בלי לרענן, לוחצים "השאילי". מוצגת הודעה אדומה מהשרת, ורשימת העותקים מתרעננת אוטומטית ומראה שהעותק מושאל.

כל הסיסמאות של משתמשי הדמו מופיעות ב-README של השרת.

## מבנה

```
src/
  api/          כל הפניות לשרת. client.js: מוסיף את ה-token, ומתרגם שגיאות להודעה בעברית עם מזהה הבקשה
  auth/         מי מחוברת (AuthContext), והגנה על דפים לפי תפקיד (RequireAuth)
  components/   רכיבים משותפים: כרטיס ספר, עימוד, הודעת שגיאה, רשימת השאלות ועוד
  hooks/        useApi: טעינה ושגיאות לכל המסכים. useReturnLoan: החזרת ספר
  pages/        המסכים
  utils/        תפקידים ועיצוב תאריכים
```

ההרשאות בלקוח הן נוחות בממשק בלבד. ההרשאה האמיתית נבדקת בשרת.
